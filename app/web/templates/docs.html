AI 联网预算

自动搜索只适合需要当前事实的问题；普通聊天不会为了闲聊去搜索。
抓网页和搜索上下文受全局配置限制：
ai_web_fetch_limit / ai_web_search_result_limit
ai_web_context_char_limit / ai_web_fetch_max_bytes / ai_web_fetch_snippet_chars

可用 /config set ai_web_tools_enabled false 关闭全部联网上下文。
